The dice used to count down a [[Hexcrawl Rules/Event Clocks/Event Clocks\|Event Clock]], starts out as a d6 and can increase or decrease in size over time in the following order of steps, d6 <-> d8 <-> d10 <-> d12 <-> d20. Each event clock has its own rules for determining when a the clock dice changes size.

If rolled with advantage, roll two clock dice and use the lower of the two results to subtract from the event clock, if rolled with disadvantage use the higher result instead.
