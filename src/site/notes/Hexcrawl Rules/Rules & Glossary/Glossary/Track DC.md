A track DC refers to the difficulty a skill check has to beat to discover and/or follow tracks left behind by a creature to track that creature or follow the same path/trail. If the character has made an active skill check to hide or cover up their tracks, the result of that check is the DC. Otherwise refer to the table bellow.

**TRACK DCs**

| **SURFACE**                                           | **DC**       |
| ----------------------------------------------------- | ------------ |
| Very soft ground (snow, wet mud)                      | 5            |
| Soft ground (sand)                                    | 10           |
| Firm ground (fields, woods, thick rugs, dusty floors) | 15           |
| Hard ground (bare rock, indoor floor, streambeds)     | 20           |
|                                                       |              |
| **CONDITION**                                         | **MODIFIER** |
| Multiple people                                       | -2           |
| Large group                                           | -4           |
| Very large group                                      | -8           |
| Creature is bleeding                                  | -4           |
| Every day since the trail was made                    | +1 per day   |
| Every hour of rain since the trail was made           | +1 per hour  |
| Fresh snow cover since the trail was made             | +10          |
