The reaction table can be used to determine the attitude/reaction creatures have towards the party. To use the table roll 2d6 once an encounter is triggered. The table can also be used to determine the reactions creatures have towards other creatures that are part of an encounter if multiple are triggered at the same time. 

| 2d6   | Reaction             |
| ----- | -------------------- |
| 2-3   | Immediate Attack     |
| 4-5   | Hostile              |
| 6-8   | Cautious Threatening |
| 9-10  | Neutral              |
| 11-12 | Amiable              |
