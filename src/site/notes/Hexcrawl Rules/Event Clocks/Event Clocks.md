Inspired by and based on this [post](https://goblinpunch.blogspot.com/2023/04/the-underclock-fixing-random-encounter.html).

To create a sense of suspense, meaning to the passage of time and triggering events and encounters different types of [[Hexcrawl Rules/Event Clocks/Event Clocks\|Event Clocks]] can be used. The clocks can be used to foreshadow events or provide clues and provide an additional source of information for player choice if the clocks are shown to the players (recommended for all clocks apart from the [[Hexcrawl Rules/Event Clocks/Faction Clock\|Faction Clock]]). 
### Clock Countdown
An event clock usually starts at 20 and counts down to 0 using a dice, this is called a *[[Hexcrawl Rules/Event Clocks/Clock Cycle\|Clock Cycle]]*. Once the clock goes below zero an event or encounter is triggered, usually using a random table, and the clock then resets to its starting value, starting a new clock cycle. 
Each clock has its own rules for when the dice should be rolled and how much time a roll represents. Once a dice has been rolled, subtract the result from the clock. The dice usually starts of as a d6 and increases or decreases in size in the following order of steps, d6 <-> d8 <-> d10 <-> d12 <-> d20, over time, each clock has its own rules for when the dice increases and decreases in size. 
It is recommended when using a clock to roll the resulting encounter at the start of a new clock cycle to enable clues/foreshadowing and reducing the time it takes to roll and set up in session. Additionally the starting value can be changed to reduce the frequency of triggered events and encounters or simulate differences between factions if using the [[Hexcrawl Rules/Event Clocks/Faction Clock\|Faction Clock]]. 
### Core Mechanics
A Clock and its Dice usually has the following mechanics:
1. The dice explodes. If you get its *maximum value* (a 6 on a d6), immediately roll the dice again and subtract the combined value from the Clock
2. If the Clock _drops below 0_, an Encounter is triggered.  After the Encounter resolves, the clock resets.
3. If the Clock _equals 0 exactly_, it resets to 3 (optional for the [[Hexcrawl Rules/Event Clocks/Faction Clock\|Faction clock]])
4. If the Clock _equals 3 exactly_, a Foreshadowing Event occurs. So the clock reaches 0, it bounces up to 3 and a Foreshadowing Event occurs.  (These are just omens/spoor/clues, more or less.)

The following types of clocks can be used:
The [[Hexcrawl Rules/Event Clocks/Overclock\|Overclock]] is used to generate events happening while the players explore the hexmap.
The [[Hexcrawl Rules/Event Clocks/Underclock\|Underclock]] is used to to generate events happening while the players are exploring a dungeon or specific location such as a fort or outpost.
The [[Hexcrawl Rules/Event Clocks/Faction Clock\|Faction Clock]] is used to simulate the actions the factions on the hexmap take and their effects as the players explore and rest.
