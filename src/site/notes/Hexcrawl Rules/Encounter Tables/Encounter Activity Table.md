The Encounter Activity Table is used to generate an activity [[Hexcrawl Rules/Rules & Glossary/Hexcrawl Encounter Rules\|encountered]] creatures are performing when the encounter is triggered. 

To use the table roll a d12 for non-intelligent creatures and a d30 for intelligent creatures and refer to the table below. 

| Roll | Activity                                |
| ---- | --------------------------------------- |
| 1    | Lost                                    |
| 2    | Hurt                                    |
| 3    | Trapped                                 |
| 4    | Sleeping                                |
| 5    | Eating                                  |
| 6    | Sick                                    |
| 7    | Tracking Prey                           |
| 8    | Lying in Ambush                         |
| 9    | Mating Behaviour                        |
| 10   | Starving                                |
| 11   | Returning Home                          |
| 12   | Fleeing                                 |
| 13   | Plotting                                |
| 14   | Holding Captives                        |
| 15   | Scavenging                              |
| 16   | Building a Camp                         |
| 17   | Demolishing                             |
| 18   | Doing Drugs or Drinking                 |
| 19   | Artistic Pursuit                        |
| 20   | Spying                                  |
| 21   | Playing Games                           |
| 22   | Searching                               |
| 23   | Religious Ritual                        |
| 24   | Setting, Putting Out, or Fleeing a Fire |
| 25   | Weeping                                 |
| 26   | Excreting                               |
| 27   | Bathing                                 |
| 28   | Debating                                |
| 29   | Gloating                                |
| 30   | Something not on the table              |
