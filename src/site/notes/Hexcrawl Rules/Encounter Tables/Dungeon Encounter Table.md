The Dungeon [[Hexcrawl Rules/Rules & Glossary/Hexcrawl Encounter Rules\|Encounter Table]] is used to decide which encounter is triggered by the [[Hexcrawl Rules/Event Clocks/Underclock\|Underclock]]. The encounter is decided by rolling 2d6 and using the chosen event or rolling on the relevant table if needed. 

Most of the tables entries are generated from other tables and/or specific questions found in Generating and Replenishing Encounters section of the [[Hexcrawl Rules/Rules & Glossary/Hexcrawl Encounter Rules\|Hexcrawl Encounter Rules]]. Usually the results of these rolls are made beforehand and entered as an entry into this list before the session and generation during the session is only done if the same result is rolled multiple times.
